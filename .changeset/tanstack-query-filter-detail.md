The TanStack Query Window can filter the active tab by text and status. Selecting a row shows its full key, data (or mutation variables) in the JSON view, shortened until expanded, and the error with its stack. Failed rows are marked, mutation variables are summarised, and two queries that print as the same key are flagged. Creating two plugins with the same id throws.
